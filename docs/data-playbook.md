# 免费数据采集 SOP

## 每周采样表

统一用 `data/candidates.csv` 的 `product_id`，原始文件放入 `data/raw/YYYY-MM-DD/`（原始目录默认不提交）。每条记录必须有地区、采样时间、URL/关键词、原始指标和截图或 CSV 文件名。

| 来源 | 操作 | 最少记录 | 用途 |
|---|---|---:|---|
| Amazon SG Best Sellers | 进入相关类目记录前 20、价格、评分数 | 20/类目 | 本地成交代理 |
| Shopee SG / Lazada SG | 无登录窗口搜索固定英文词，记录自然结果 | 20/词/平台 | 价格带、销量显示、竞争密度 |
| Google Trends | 地区 SG；近 12 月和 90 天；导出 CSV | 2 窗口/词 | 趋势、季节性、加速度 |
| TikTok Creative Center | 地区 SG；近 7/30 天；按 Reach、CTR、2s/6s 分别观察 | 20/类目 | 内容与商业意图 |
| Meta Ads Library | 国家 SG；搜索 3 个同义词；记录活跃广告主和首投日期 | 3 词/方向 | 广告主重复与持续性 |
| 1688 | 固定规格询价，不能混用不同材质/尺寸 | 3 家/候选 | MOQ、成本、重量、交期 |

## 防止数据误读

- 不把评论总数当近期销量；同时记录最近 30/90 天评论增量。
- 不把 Google Trends 的 100 当绝对搜索量；同批次比较，保存关键词组合。
- 不把广告曝光当成交；Reach/播放留存与 CTR/CVR 分开记录。
- 不把一个平台的榜首外推为新加坡全市场；至少两个独立层级交叉验证。
- 不抓取登录后、验证码后或 robots/条款明确限制的内容；改用人工记录或官方导出。
- 不采购带品牌名、角色形象、专利结构暗示但无法提供授权链的商品。

## 供应商询价模板

```text
目标市场：新加坡。请按同一规格回复：
1. 20 / 50 / 200 件含税单价与 MOQ
2. 单件净重、含包装毛重、外箱尺寸与装箱数
3. 打样费、交期、补货周期、瑕疵率与赔付条款
4. 材质报告、适用认证、电池型号/MSDS/UN38.3（如适用）
5. 是否涉及商标、外观、专利或角色授权；请提供权利链文件
6. 中性包装与英文标签能力
```

## 更新流程

1. 将平台原始记录保存并写明日期。
2. 更新候选行的证据说明、评分与真实报价。
3. 运行 `PYTHONPATH=src python3 -m sg_product_research.cli`。
4. 查看 `generated/ranking.md`，只为 `TEST` 项提交采购审批。
5. 对每个 `TEST` 项执行 HS/CA Product Code Checker，并把确认结果归档。
